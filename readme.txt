💡 [2단계] 공개된 구글 캘린더나 크롤링 API 활용하기 (난이도: 중)
서브컬쳐 게임들은 유저들이 자발적으로 '구글 캘린더'에 게임 일정을 정리해 공유하는 경우가 많습니다.

공개된 구글 캘린더의 API Key를 발급받으면, 백엔드 서버를 직접 만들지 않고도 내 웹 달력으로 일정을 바로 불러올 수 있습니다.

💡 [3단계] 파이썬 크롤러 + 노드 서버 구축 (난이도: 상)
원하는 정보 사이트에서 완전히 자동으로 긁어오고 싶을 때 도전하는 마스터 단계입니다.

Python으로 하루에 한 번 게임 공지사항을 긁어오는 크롤러를 만듭니다.

데이터를 데이터베이스(DB)에 저장합니다.

Node.js나 Python 서버를 하나 열어서, 내 웹 달력이 켜질 때 이 데이터를 보내주도록 연결합니다.
